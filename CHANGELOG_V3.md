# آيات AYAT – V3

## Added
- Search Quran verses by Arabic keyword or phrase.
- Display verse text, surah name, surah number, and ayah number.
- Copy verse text.
- Save and remove favorite verses locally with SharedPreferences.
- Open Quran search from the home dashboard and Islamic hub.

- Simplified the page response key lookup in QuranService.
