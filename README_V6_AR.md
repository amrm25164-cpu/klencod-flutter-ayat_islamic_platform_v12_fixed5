# آيات AYAT — الإصدار V6

## الجديد
- شاشة «رفيق آيات الذكي» باللغة العربية.
- خادم وسيط Node.js لحماية مفاتيح مزودي الخدمات بعيداً عن التطبيق.
- ربط اختياري مع OpenAI من الخادم فقط.
- واجهة موحدة لمزود حديث خارجي مرخّص؛ تظل متوقفة بوضوح حتى إعداد المزود.
- حفظ عداد الأذكار والسبحة والذكر الحالي على الجهاز.
- ربط المساعد من الصفحة الرئيسية والمركز الإسلامي.

## تشغيل الخادم
1. ثبّت Node.js 20 أو أحدث.
2. ادخل إلى مجلد `backend`.
3. انسخ `.env.example` إلى `.env`.
4. أنشئ قيمة عشوائية طويلة لـ `AYAT_APP_TOKEN`، وأضف `OPENAI_API_KEY` إذا أردت تفعيل المساعد.
5. نفّذ `npm install` ثم `npm start`.

## تشغيل Flutter
```bash
flutter pub get
flutter run --dart-define=AYAT_API_BASE_URL=https://YOUR-SERVER/api --dart-define=AYAT_APP_TOKEN=YOUR-TOKEN
```

## الصراحة التقنية
لا يوجد خادم منشور أو مفاتيح مزودين مرفقة. لذلك لن يعمل المساعد الفعلي قبل إعداد الخادم ومفتاح OpenAI، ولن يعمل بحث الحديث قبل ربط مزود حديث مرخّص. رمز التطبيق المضمّن في APK يمكن استخراجه، ولذلك لا يغني عن تسجيل دخول المستخدمين ورموز قصيرة العمر في الإنتاج. لم يتم بناء APK أو اختباره لأن Flutter SDK غير متاح في بيئة إنشاء هذه النسخة.

## ملاحظة إنشاء مشروع Android
النسخة المصدرية الموروثة لا تحتوي على مجلد منصة Android أو ملفات Gradle. بعد تثبيت Flutter على جهاز التطوير، من جذر المشروع نفّذ:
```bash
flutter create --platforms=android --project-name ayat .
flutter pub get
flutter analyze
flutter build apk --release
```
راجع `applicationId` واسم الحزمة وصلاحيات Android قبل النشر. هذه الخطوات تنشئ ملفات المنصة الناقصة؛ لا تنفذها على نسخة العمل الوحيدة قبل الاحتفاظ بنسخة احتياطية.

## V12 — مزامنة الآيات مع التلاوة
من مكتبة القراء اضغط أيقونة المزامنة لفتح شاشة مزامنة الآية. تعتمد المزامنة على توقيتات المقاطع التي يوفرها Quran.com API، وتقوم بتظليل الآية الحالية أثناء تشغيل الصوت. يمكن الضغط على آية للانتقال إلى بدايتها. ليست كل التسجيلات أو المصادر تضمن توفير بيانات توقيت؛ عند غيابها تظهر رسالة بدلاً من اختراع توقيت غير دقيق.
